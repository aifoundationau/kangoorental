    Default currency & token value

    The default currency is AUD$ and the default token price is 1 token = AUD$1. All invoices are issued in Australian dollars.

    Products & services — discount %, price & customizable tokens

    Type the discount % for days 2–7 to automatically calculate the AUD$ price and tokens, or adjust them directly. By default, 1 token = AUD$1 (inc GST).
